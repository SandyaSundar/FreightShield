# harbor_flich_email_router Flow

This project defines a declarative CrewAI Flow in `src/harbor_flich_email_router/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/harbor_flich_email_router/flow.yaml` to change the flow. Add reusable crews under `src/harbor_flich_email_router/crews/`, custom Python tools under `src/harbor_flich_email_router/tools/`, and shared knowledge files under `src/harbor_flich_email_router/knowledge/`.
